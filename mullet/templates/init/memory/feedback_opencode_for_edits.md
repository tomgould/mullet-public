For any task involving file writes or edits, use mcp__mullet__mullet_opencode.
mullet_run is for text-output tasks only (research, analysis, summaries).

**Why:** AI Bridge was removed. mullet_opencode has native filesystem access and is faster and more reliable.
**How to apply:** File edits → mullet_opencode. Text output → mullet_run.
